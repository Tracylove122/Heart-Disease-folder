❤️Heart Disease Prediction
This project explores how machine learning can predict the likelihood of heart disease using patient data. I worked with a real dataset containing features like age, cholesterol, chest pain type, and more — aiming to build a model that helps doctors make quicker, data-driven decisions.

 
 
 What’s Inside:
Cleaned and analyzed health data with features like:

Age, Sex, Blood Pressure, Cholesterol, ECG Results, Heart Rate,etc

Explored the data visually (heatmaps, bar charts, etc.)

Used different models to make predictions:

Logistic Regression

Random Forest

Decision Tree

Linear Regression (for analysis)

Evaluated performance with:

Accuracy, F1-score, Confusion Matrix, ROC Curve

Visualized the decision tree to show how predictions were made

 Why It Matters:
Predicting heart disease early can save lives. This project combines health and data science to make that happen   in a simple, interpretable way.
